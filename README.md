# কাজী এগ্রোটেক (Kazi Agrotech) - Poultry Farm Management System

একটি আধুনিক ও সম্পূর্ণ পোল্ট্রি খামার ব্যবস্থাপনা অ্যান্ড্রয়েড অ্যাপ্লিকেশন (Jetpack Compose & Kotlin)। 

এই সংস্করণটি কলেজ অ্যাসাইনমেন্ট এবং প্রজেক্ট প্রেজেন্টেশনের জন্য বিশেষভাবে প্রস্তুত করা হয়েছে — কোনো এক্সটার্নাল ডাটাবেজ বা ইন্টারনেটের উপর নির্ভর না করে সম্পূর্ণ ফ্রন্টএন্ড ও ইন-মেমোরি স্টেট ম্যানেজমেন্টের মাধ্যমে অফলাইনে তাৎক্ষণিকভাবে চমৎকারভাবে কাজ করে।

---

## 📱 মূল ফিচারসমূহ (Key Features)

1. **ড্যাশবোর্ড (Dashboard Overview)**:
   - আজকের মোট ডিম উৎপাদন, ডিম বিক্রয়, ডিমের দর এবং মোট আয়।
   - খামারের মোট জীবিত ও মৃত মুরগীর হিসাব।
   - লাইভ ডিমের স্টক ও চলতি মাসের সামগ্রিক লাভ-ক্ষতির সামারি।
   - দ্রুত নেভিগেশনের জন্য স্ট্যাটাস কার্ডস।

2. **দৈনিক প্রতিবেদন (Daily Reports)**:
   - তারিখভিত্তিক ডিম সংগ্রহ, বিক্রয় এবং মৃত মুরগীর সংখ্যা এন্ট্রি ও এডিট।
   - রিয়েল-টাইম স্টক ক্যালকুলেশন ও ফিল্টারিং (মাস ও সার্চ অনুযায়ী)।
   - প্রতিটি রিপোর্টের বিস্তারিত ভিউ এবং সরাসরি প্রিন্টযোগ্য PDF প্রিভিউ ও শেয়ারিং।

3. **মাসিক খরচ (Monthly Expenses)**:
   - খাদ্য/ফিড, ওষুধ ও ভ্যাকসিন, বিদ্যুৎ বিল, যাতায়াত এবং রক্ষণাবেক্ষণ খরচ ট্র্যাকিং।
   - সম্পূর্ণ খরচ ভিউ এবং রিপোর্ট অ্যানালাইসিস।

4. **শেয়ারহোল্ডার ও কর্মী ব্যবস্থাপনা (Stakeholders & Staff)**:
   - শেয়ারহোল্ডারদের বিনিয়োগ ও লভ্যাংশ বন্টন হিসাব।
   - খামার স্টাফদের তালিকা ও মাসিক বেতন পরিশোধের ইতিহাস ও স্লিপ।

5. **অ্যানালিটিক্স ও চার্টস (Analytics & Reports)**:
   - ডিম উৎপাদন এবং খরচের ইন্টারেক্টিভ গ্রাফ ও ট্রেন্ড চার্ট।
   - সম্পূর্ণ ডেটা CSV ফাইল আকারে এক্সপোর্টের সুবিধা।

6. **রোল ও পারমিশন (Role-Based Access Control)**:
   - অ্যাডমিন (Admin), ম্যানেজার (Manager), সুপারভাইজার (Supervisor) এবং কর্মী (Worker) ভিত্তিক ডাইনামিক অনুমতি।

## 🛠️ প্রযুক্তি (Technology Stack)

- **Language**: Kotlin 2.2
- **UI Toolkit**: Jetpack Compose (Material 3)
- **Architecture**: MVVM (Model-View-ViewModel) + Clean Architecture
- **State Management**: Kotlin Coroutines & StateFlow
- **Image Loading**: Coil Compose
- **Target SDK**: Android 16 (API 36), Min SDK: Android 7.0 (API 24)

## 🚀 কীভাবে নতুন GitHub-এ পুশ করবেন এবং APK বানাবেন

### ধাপ ১: গিট ইনিশিয়ালাইজ ও পুশ
প্রজেক্ট ফোল্ডারে টার্মিনাল খুলে নিচের কমান্ডগুলো চালান:

```bash
git init
git add .
git commit -m "Initial commit - Kazi Agrotech Frontend Assignment"
git branch -M main
git remote add origin https://github.com/<আপনার-ইউজারনেম>/<আপনার-নতুন-রিপো>.git
git push -u origin main
```

### ধাপ ২: GitHub Actions দিয়ে ১ ক্লিকে APK তৈরি
এই প্রজেক্টে সম্পূর্ণ অটোমেটেড GitHub Actions ওয়ার্কফ্লো (`.github/workflows/build-apk.yml`) যুক্ত করা আছে:
1. কোড GitHub-এ পুশ করার সাথে সাথে অটোমেটিক বিল্ড শুরু হবে।
2. অথবা আপনার রিপোজিটরির **Actions** ট্যাবে গিয়ে **Build Android APK** এ ক্লিক করে **Run workflow** চাপুন।
3. বিল্ড শেষ হলে (সবুজ টিক চিহ্ন) রানের ভেতর ঢুকে নিচে **Artifacts** সেকশন থেকে `kazi-agrotech-debug-apk` জিপ ফাইলটি ডাউনলোড করে নিন। আনজিপ করলেই পেয়ে যাবেন রেডি `app-debug.apk`!

## 💻 লোকাল মেশিনে বিল্ড করার নিয়ম

যদি আপনার কম্পিউটারে অ্যান্ড্রয়েড স্টুডিও থাকে:
1. **Android Studio** খুলে **Open** দিয়ে এই `kazi-agrotech-frontend` ফোল্ডারটি সিলেক্ট করুন।
2. গ্র্যাডল সিঙ্ক শেষ হলে মেনু থেকে **Build > Build Bundle(s) / APK(s) > Build APK(s)** দিন।
3. অথবা টার্মিনাল থেকে রান করুন:
   - উইন্ডোজ: `.\gradlew.bat assembleDebug`
   - ম্যাক/লিনাক্স: `./gradlew assembleDebug`
4. তৈরি হওয়া APK পাওয়া যাবে: `app/build/outputs/apk/debug/app-debug.apk`
